## 1. 人行道（含淨寬）

| 項目 | 內容 |
|---|---|
| 資料集 | 人行道，`data.gov.tw/dataset/58791` |
| 提供機關 | 內政部國土管理署 |
| 授權 | 政府資料開放授權條款第 1 版（**須標示出處**） |
| 更新 | 不定期；資料集最後更新 2026-07-02 |
| 採用版本 | `SIDEWALK_202606`（2026 年 6 月），90.26 MB ZIP |
| SHA-256 | `268bab7f31560beb5196eecfa2ebfd3093076f4105b64e98c474e9810b0aaddc` |

### 內容結構

壓縮檔內為 **22 縣市 × 2 種座標系統**的 GeoJSON，共 44 檔，另有三個 manifest CSV（無欄位說明）。解壓後總計 894 MB。

**已提供 WGS84 版本，無須自行轉換座標。** 檔名格式 `SIDEWALK_<縣市>_202606_<WGS84|TWD97>.geojson`，CRS 宣告為 `urn:ogc:def:crs:OGC:1.3:CRS84`。

幾何型別為 **MultiPolygon**——人行道的實際鋪面範圍，不是道路中心線。

### 欄位

| 欄位 | 意義 | 備註 |
|---|---|---|
| `NAME` | 道路名稱 | |
| `PSTART` / `PEND` | 路段起點／迄點 | 以交叉路名表示 |
| `SW_DIRECT` | 人行道方向 | **1 = 東／南側，2 = 西／北側，3 = 徒步區** |
| `SW_LENG` | 長度（公尺） | |
| `SW_WTH` | 人行道寬度 | |
| `SWW_WTH` | **人行道淨寬** | 扣除固定設施後的可通行寬度 |
| `SW_RAMP` | 路緣斜坡數量 | |
| `COUNTY_NA` | 縣市 | 台北市寫作「台北市」（非「臺」） |
| `VILL_NAME` | 行政區 | 欄名為 village 但實際存放區名 |

### 實測（台北市）

- **18,304 段**，與前案顯示的數字一致。
- 十個欄位**全數 100% 填值，無 null、無 0 值**。
- 淨寬 0.32 – 15.10 公尺，中位數 1.35，平均 1.70。
- 淨寬分級：**紅（< 1.5 m）58.6%**、黃（1.5–2.5 m）27.1%、綠（≥ 2.5 m）14.3%。
- 淨寬等於總寬者占 45.6%，即逾半數路段的可通行寬度因固定設施而縮減。
- `SW_DIRECT` 實際值：1 共 9,370、2 共 8,870、3 共 64。
- 涵蓋 12 個行政區，大安區 2,524 段（紅 56.7%）。

### 檔案大小（WGS84，未簡化）

新北市 118 MB、高雄市 99 MB、台中市 76 MB、台北市 52 MB、桃園市 35 MB。

前案處理後為 0.03–6.2 MB／縣市，落差一至兩個數量級，須於前處理階段做幾何簡化與屬性精簡（design D14）。

### 重要限制

**本資料集僅收錄「有人行道之處」。** 沒有人行道的道路不會出現在其中。以路名字串比對大安區學校周邊 286 段 OSM 道路，**55.9% 查無人行道紀錄**；對不到的 99 個路名中有 89 個是巷弄。

因此「不在本資料集中」不等於「淨寬為零」，也不能逕自斷言「沒有人行道」——路名比對本身即有偏誤。呈現與敘述一律以「查無人行道紀錄」表述（design D6、D13）。

## 2. 道路中心線

| 項目 | 內容 |
|---|---|
| 來源 | OpenStreetMap |
| 授權 | ODbL 1.0（**須標示出處；公開散布衍生資料庫時須以相同授權分享**） |
| 取得方式 | Overpass API（`overpass-api.de/api/interpreter`） |

用途：呈現查無人行道紀錄的道路，使地圖不致讓人誤以為該處無路可走。

**沿用既有作法**：`daan-school-geojson/build_daan_school_geojson.py` 已實作 Overpass 查詢，含快取與重試（4 次、間隔 30 秒），並以 `way["highway"~...]` 依道路等級篩選、以 geopandas／shapely 後處理。擴充至縣市尺度時延續此路線。

**不採 Geofabrik 離線檔**：台灣 `.osm.pbf` 為 311.8 MB、shapefile 為 249.5 MB，且需額外的 osmium／pyrosm 工具鏈。Overpass 配合快取可直接取得所需的道路等級子集，無須扛整份離線檔。

需排除學童不會步行的類別（高架、快速道路等），排除規則於實作時明列並記錄（task 3b.1）。

| 提供機關 | 內政部國土測繪中心 |
| 授權 | 政府資料開放授權條款第 1 版（須標示出處） |

尚未下載勘查。已知限制（取自 `daan-school-geojson/README.md`）：

- 來源為臺灣通用電子地圖區塊圖層，平面精度 2.5 公尺，非地籍界。
- 資料月份不一，大安區 49 個面中 39 個為 2020-06。
- 不含幼兒園；部分大專校院的分部與教育中心列為獨立學校。
- 校名未合併（例如「開平餐飲學校」與「開平餐飲職業學校」分列）。
- **無學校類型欄位**，須另接教育部學校名錄（design D3）。

`daan-school-geojson` 現有檔案只保存了外環 **LineString**，本專案需要**多邊形**，須自來源重新產出（task 4.1）。
