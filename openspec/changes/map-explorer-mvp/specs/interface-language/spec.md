# Spec Delta

## Purpose

定義中英文介面切換的行為：涵蓋範圍、資料值與介面文字的界線，以及語言選擇的保存與初始判定。

## ADDED Requirements

### Requirement: 提供中英文切換

系統 SHALL 提供中文與英文介面切換。切換 MUST NOT 導致重新載入資料或遺失目前的篩選與檢視狀態。

#### Scenario: 切換語言

- **WHEN** 使用者切換介面語言
- **THEN** 介面文字改以該語言呈現，目前的縣市、篩選條件、地圖位置與比較清單皆維持不變

### Requirement: 切換涵蓋全部介面文字

語言切換 SHALL 涵蓋所有介面文字，包含篩選標籤、**圖例**、詳細面板欄位名稱、比較面板、統計摘要、錯誤訊息與資料來源標示。

#### Scenario: 檢查圖例

- **WHEN** 使用者切換至英文
- **THEN** 圖例的級距說明與學校類型標籤一併改為英文，不留中文殘留

#### Scenario: 錯誤訊息

- **WHEN** 資料載入失敗且介面為英文
- **THEN** 錯誤訊息以英文呈現

### Requirement: 資料值不翻譯

來源資料的值 SHALL 依原文呈現，不予翻譯。系統 MUST NOT 自行翻譯路名、校名或行政區名。

#### Scenario: 英文介面下的路名

- **WHEN** 介面為英文且使用者檢視某路段詳細
- **THEN** 欄位名稱為英文，路名維持來源資料的中文原文

### Requirement: 保存語言選擇

系統 SHALL 記住使用者的語言選擇，於再次開啟時沿用。

#### Scenario: 再次開啟

- **WHEN** 使用者曾切換為英文，稍後重新開啟本工具
- **THEN** 介面以英文呈現

#### Scenario: 首次開啟

- **WHEN** 使用者首次開啟且無先前選擇
- **THEN** 系統以中文為預設，使用者可隨時切換
