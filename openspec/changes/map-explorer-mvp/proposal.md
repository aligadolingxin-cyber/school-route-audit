# Proposal

## Why

學童通學路上的步行環境資料，目前散在三個互不相通的政府開放資料集：內政部國土管理署的人行道圖資（含淨寬）、內政部警政署的傷亡交通事故資料、國土測繪中心的各級學校範圍圖。家長、學校與里鄰無從得知自家孩子的通學路上人行道有多寬、哪裡窄到不能走、哪裡出過致命事故。

本專案將三者疊在同一張地圖上，以**路段**為單位呈現，並提供街景核對與路段並排比較，使「這條路對孩子安不安全」成為可以被指著看、被比較、被討論的東西。

開放資料能回答的只有「有沒有人行道、多寬、有沒有出過事」。騎樓被佔用、行穿線品質、路口視距、機車停放這些同樣決定安全的因素，沒有任何資料集收錄。這部分由 `school-route-audit-mvp` 的逐段人工評估產出，後續接入本工具作為風險圖層。本 change 只做開放資料能支撐的部分。

## What Changes

- 新增地圖探索介面，以縣市為單位按需載入資料。
- **學校以半透明地塊多邊形呈現**，依類型（國小／國中／高中職／大專／特殊／其他）分色，附 300 公尺生活圈。不使用點位標記。
- **人行道以實際鋪面多邊形呈現**，依淨寬分三級著色：紅（< 1.5 m）、黃（1.5–2.5 m）、綠（≥ 2.5 m）。不以單一經緯度代表整條道路。
- **另以 OSM 道路中心線圖層呈現查無人行道紀錄的道路**，以灰色標示。人行道資料僅收錄有人行道之處，若不另畫道路，地圖會使人誤以為該處無路可走。此一比例為主要統計數字，與三個淨寬級距並列。
- 新增 A1 致命事故點圖層。
- 篩選條件變動時，地圖與統計摘要同步更新。
- 點擊路段開啟詳細資料面板：淨寬、路緣斜坡、事故、風險分數拆解、問題摘要與改善建議。
- 地圖與 Google 街景聯動，可開啟該路段街景核對現場。
- 最多三條路段並排比較，同欄對照各項指標。
- 中英文介面切換。
- 圖例固定於地圖下側，文字與顏色並用。
- **缺失資料一律顯示「未提供」，不得顯示為 0 或以 0 參與計算。**查無人行道紀錄者以「查無人行道紀錄」表述，不得斷言為「沒有人行道」。

## Capabilities

### New Capabilities

- `region-selection`：縣市、行政區、學校類型與目標人群的篩選；資料依縣市按需載入；篩選結果的統計摘要與地圖同步。
- `school-zones`：學校地塊多邊形的呈現、依類型分色、300 公尺生活圈，以及依目標人群調整的可及範圍。
- `road-segments`：路段幾何呈現、依人行道淨寬分級著色、未提供資料的表示方式，以及圖例。
- `crash-points`：A1 致命事故點圖層的呈現、依運具與死亡人數的視覺編碼，及其與淨寬圖層的疊合判讀。
- `segment-detail`：點擊路段後的詳細資料、風險分數拆解、問題摘要與改善建議，以及所有衍生敘述必須標明資料依據的約束。
- `street-view`：地圖與街景的雙向聯動、街景不可用時的退場行為。
- `segment-comparison`：二至三條路段的並排比較與差異呈現。
- `interface-language`：中英文介面切換與語言狀態的保存。

### Modified Capabilities

（無）

## Impact

- **前案**：已有公開工具 [Taiwan Mobility Atlas](https://yunching0513.github.io/taiwan-mobility-atlas/sidewalk.html)（原始碼 `github.com/yunching0513/schoolzone`）涵蓋本 change 的多數圖層，且為全國規模。本專案與其重疊的部分不主張原創；差異化在後續接入的逐段評估層。實作前應檢視其授權條款，界定可參考與不可直接取用的範圍。

- **資料來源與授權義務**：
  - 人行道圖資（含 `SWW_WTH` 淨寬）— 內政部國土管理署，政府資料開放授權條款第 1 版，須標示出處。2026 年 6 月版為分縣市 GeoJSON，已具 WGS84 版本，幾何為 MultiPolygon。
  - 道路中心線 — OpenStreetMap，ODbL 1.0，用於呈現查無人行道紀錄的道路。須標示出處；公開散布衍生資料庫時須以相同授權分享。
  - 傷亡道路交通事故資料 — 內政部警政署，107 年起含經緯度。
  - 各級學校範圍圖 — 國土測繪中心，政府資料開放授權條款第 1 版。
  - 底圖 — OpenStreetMap，ODbL 1.0，須標示出處。
  - 本工具將以網址對外可存取，即構成散布，上述標示為**義務而非禮貌**。

- **學校資料的既有落差**：現有 `daan-school-geojson` 僅保存學校範圍的外環 LineString，本 change 需要**多邊形**，須自來源資料集重新產出，且範圍由大安區擴及全國分縣市。

- **學校分類**：類型非來源資料集的現成欄位，須接教育部學校名錄，不得以校名字串推測。

- **新外部相依**：Google Maps JavaScript API（街景）。需要具計費帳號的金鑰，由使用者自行申請。金鑰於前端可見，**必須設定 HTTP referrer 限制與用量上限**。

- **與 `school-route-audit-mvp` 的關係**：該 change 產出的評估結果將作為風險圖層接入本工具。本 change 需在 `segment-detail` 與 `road-segments` 預留其接入位置，但不實作。兩者以路段識別碼對應。

- **不在本 change 範圍**：障礙物點圖層、共同繪圖、個別旅程圖、街道願景提案。
