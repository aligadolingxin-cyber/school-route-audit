# Google 試算表同步

讓幾位評估者分工標記，結果彙總於一份共用試算表。

## 這不是權限控制

端點部署為「任何人都可存取」，`TOKEN` 只是路障——擋掉隨機掃描，擋不住有心人。**真正的保護是網址不公開。**

實際得到的是：每個人署名、各自分工、成果合併。不是登入、不是權限。若日後需要真正的權限控制，應改用具認證的後端。

**localStorage 仍是主要儲存**，試算表是同步目標。網路斷掉不會掉資料。

## 設定步驟

**一、建立試算表**

到 [sheets.new](https://sheets.new) 開一份新試算表，取個名字。工作表會由腳本自動建立，不用手動加。

**二、貼上腳本**

試算表選單 → **擴充功能 → Apps Script**。

把 `Code.gs` 的內容整份貼上，覆蓋原本的 `function myFunction()`。

**三、改掉 TOKEN**

第 16 行：

```javascript
const TOKEN = 'CHANGE-ME-到一段夠長的隨機字串';
```

換成一段夠長的隨機字串（20 字以上）。這個字串等下要填進工作台。

**四、部署**

右上角 **部署 → 新增部署作業**：

| 欄位 | 值 |
|---|---|
| 類型 | 網頁應用程式 |
| 執行身分 | 我 |
| 誰可以存取 | **任何人** |

第一次會要求授權，按「審查權限」→ 選你的帳號 → 「進階」→「前往（不安全）」→ 允許。那個警告是因為腳本未經 Google 審核，是你自己寫的。

部署完會得到一個 `https://script.google.com/macros/s/.../exec` 網址。

**五、填進工作台**

開[評估工作台](../../app/audit.html)，點「同步設定」，填入：

- 端點網址（上一步取得的）
- TOKEN（第三步設定的）
- 你的署名

這三項存在你自己的瀏覽器，不進版本庫。

**每位評估者都要做第五步**，用同一組網址與 TOKEN，但署名各自不同。

## 分派

試算表會自動產生「分派」工作表，兩欄：

| 評估者 | 單位識別碼 |
|---|---|
| 王小明 | c547ce0b5b75 |
| 李小華 | 48801111 |

自己填。工作台會讀它，讓每個人只看自己負責的段落。留空則所有人都看得到全部。

單位識別碼見 `app/data/audit/demo-units.json`。

## 同段多人評估怎麼辦

本工具的設定是**分工**，不是複評。若同一段出現多位評估者，彙總時會標示為衝突而不自行平均——那是需要人決定的事。

若你真的需要多人評同一段以取得評分者間信度，那不只是帳號問題：還要處理「後評的人看不看得到先評的答案」。那是研究設計的決定，應先修訂 spec。
